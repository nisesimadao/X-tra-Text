# X-tra Text

X（Twitter）の投稿欄に長文を入力し、その文章を画像として投稿しやすくする Chrome 拡張機能です。
140 文字を超える文章を画像へ変換し、クリップボードへコピーできます。

[英語版 README はこちら](README.md)

## 主な機能

- **自動画像生成**：長文をワンクリックで画像化し、クリップボードへコピーします。
- **自動レイアウト調整**：文字数に応じてフォントサイズと配置（中央揃えまたは左揃え）を調整します。
- **背景カスタマイズ**：単色だけでなく、任意の画像を背景に設定できます。
- **ガラス効果**：背景画像の上に半透明レイヤーを重ね、文字の可読性を保ちます。
- **リアルタイム編集**：文字サイズや縁取りの変更を、その場でプレビューへ反映します。
- **設定機能**：表示や画像生成に関する各種項目を変更できます。

## 開発者モードでのインストール

次の手順で手動インストールします。

1. このリポジトリをクローンするか、ZIP でダウンロードして展開します。
2. Google Chrome で `chrome://extensions/` を開きます。
3. 右上の「デベロッパー モード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、展開したフォルダを選択します。
5. X（x.com）を開き、投稿欄に追加された画像アイコンをクリックします。

## 技術スタック

- **Language**：JavaScript（Vanilla JS）
- **Engine**：Canvas API（High-DPI support with 2x scale）
- **Architecture**
  - `renderer.js`：高解像度レンダリング処理。
  - `ui.js`：エディタ UI。
  - `utils.js`：クリップボードとエディタ操作のユーティリティ。
